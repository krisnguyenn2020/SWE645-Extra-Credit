# Student Survey Application (Django Version)

This is a web application built with Django for collecting, storing, viewing, updating, and deleting student survey submissions.

---

```

├── manage.py

├── survey_app/

│   ├── views.py          # All backend logic (create, read, update, delete)

│   ├── urls.py           # All view routing
│   ├── templates/
│   │   └── survey_app/

```

## 🚀 Setup Instructions

1. **Clone and Set Up Environment**

```bash
python -m venv venv
venv\Scripts\activate   # Windows
pip install django
```

2. **Start Django Project and App**

```bash
django-admin startproject student_survey
cd student_survey
django-admin startapp survey_app
```

3. **Configure Installed Apps**

In `settings.py`, add:
```python
INSTALLED_APPS = [
    ...
    'survey_app',
]
```

4. **Create Model**

In `survey_app/models.py`:
```python
from django.db import models

class Survey(models.Model):
    first_name = models.CharField(max_length=100)
    last_name = models.CharField(max_length=100)
    street_address = models.CharField(max_length=255, blank=True)
    city = models.CharField(max_length=100, blank=True)
    state = models.CharField(max_length=100, blank=True)
    zip = models.CharField(max_length=20, blank=True)
    telephone_number = models.CharField(max_length=20, blank=True)
    email = models.EmailField(unique=True)
    liked_most = models.CharField(max_length=255, blank=True)
    interest_source = models.CharField(max_length=255, blank=True)
    recommendation = models.CharField(max_length=100, blank=True)
    date_of_survey = models.DateField(auto_now_add=True)
```

5. **Migrate Database**

```bash
python manage.py makemigrations
python manage.py migrate
```

6. **Run the Server**

```bash
python manage.py runserver
```

Visit: [http://127.0.0.1:8000/survey/form/](http://127.0.0.1:8000/survey/form/)

## ✅ Features Implemented

### Frontend (Templates)

| Page | File | Function |
|------|------|----------|
| Submit Survey | `survey_form.html` | Collect user input |
| Survey List   | `survey_list.html` | Display submitted surveys with **Edit**, **Delete**, **View** actions |
| View Survey   | `survey_detail.html` | Show all fields of a selected survey |

### Backend (views.py)

| Function | URL | Description |
|----------|-----|-------------|
| `submit_form()` | `/survey/form/` | Creates new survey and checks for duplicate email |
| `survey_list()` | `/survey/list/` | Lists all surveys |
| `update_survey_by_id()` | `/survey/<id>/update/` | Edits existing survey |
| `delete_survey_by_id()` | `/survey/<id>/delete/` | Deletes survey |
| `view_survey_detail()` | `/survey/<id>/detail/` | Shows survey detail in UI |
| `get_survey_by_id()` | `/survey/<id>/` | Returns JSON of survey |
| `get_all_surveys()` | `/survey/all/` | All surveys as JSON |
| `save_survey()` | `/survey/save/` | API create (POST JSON) |

## ✨ UI Behavior

- Form submission validates unique email
- Success/Error messages shown with `messages` framework
- Survey list shows table with: ID, Name, Email, City, Date
- **Edit/Delete/View** buttons in every row
- Bootstrap 5 styling + icons
