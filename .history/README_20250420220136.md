
## 📝 Student Survey - Django Version (Extra Credit)

This project is a Django-based implementation of the Student Survey web application for extra credit.

---

### 📦 Prerequisites
- Python 3.8+
- pip (Python package manager)

---

### ⚙️ Setup Instructions

#### 1. Create and activate a virtual environment:
```bash
python -m venv venv
```
- On **Windows PowerShell**:
```bash
.\venv\Scripts\Activate
```
- On **Mac/Linux**:
```bash
source venv/bin/activate
```

#### 2. Install Django:
```bash
pip install django
```

#### 3. Start a new Django project:
```bash
django-admin startproject student_survey
cd student_survey
```

#### 4. Run the server to test:
```bash
python manage.py runserver
```
Visit: [http://127.0.0.1:8000](http://127.0.0.1:8000)
