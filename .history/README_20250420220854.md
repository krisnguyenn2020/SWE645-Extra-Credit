
## 📝 Student Survey - Django Version (Extra Credit)

This project is a Django-based implementation of the Student Survey web application for extra credit.

---

### 📦 Prerequisites
- Python 3.8+
- pip (Python package manager)

---

### ⚙️ Setup Instructions

#### 1. Create and activate a virtual environment:
```bash
python -m venv venv
```
- On **Windows PowerShell**:
```bash
.\venv\Scripts\Activate
```
- On **Mac/Linux**:
```bash
source venv/bin/activate
```

#### 2. Install Django:
```bash
pip install django
```

#### 3. Start a new Django project:
```bash
django-admin startproject student_survey
cd student_survey
```

#### 4. Start your app:
Make sure you're in the same folder as `manage.py` (the project root):
```bash
python manage.py startapp survey_app
```

#### 5. Register your app:
In `student_survey/settings.py`, add `'survey_app',` to `INSTALLED_APPS`.

#### 6. Create your Survey model:
In `survey_app/models.py`, define a `Survey` class with fields like `first_name`, `last_name`, `email`, etc.

#### 7. Create the database:
Run the following to generate and apply the migrations:
```bash
python manage.py makemigrations
python manage.py migrate
```

This creates a local `db.sqlite3` file.
